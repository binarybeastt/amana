## Decisions

Choices that change the plan, a pass criterion, or the spec. Newest first.

- **2026-10-21** Phase 3 (Bluetooth mesh) built and Gate P3 passed in emulator form, 5/5. Every phone is a GATT server and client: chunked frames with SHA-256, HELLO with app id / protocol version / network, INV then push of what the peer lacks; relays verify proofs in `:core` before storing; persistent queue de-duplicated by txid with a 6-hop limit; connectivity watcher broadcasts on any network; foreground service keeps it going in Doze and after reboot. Bugs found by the tests: a stale network set kept the app "online" in airplane mode; a second lightwalletd "already mined" text; harness `pipefail` traps twice. Emulator Bluetooth (netsim) degrades after dozens of fast radio cycles, so the gate toggles Wi-Fi/data instead of airplane mode. ⚠ Restarting the emulators lost 5554's and 5556's Phase 2 testnet wallets (quick-boot snapshot + `-no-snapshot-save`); `emulators.sh` now cold-boots; new A funded from the desktop copy of the old A seed.
