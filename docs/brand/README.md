# Amana brand

**Amana**: trust, something held in good faith for someone (Hausa and Swahili, from Arabic *amānah*).
The mark is an arch keeping a green dot: a payment kept safe until it settles. The green is the
app's "settled" colour.

| File | Use |
|---|---|
| `amana-mark.svg` | Mark on dark backgrounds |
| `amana-mark-mono.svg` | One-colour mark for light backgrounds |
| `amana-icon.svg` | App icon (black square) |
| `amana-wordmark.svg` | Mark + "amana" in Inter SemiBold (text, needs Inter installed) |

Colours: black `#050505`, white `#F2F2F7`, green `#30D158`. Font: Inter (`android/app/src/main/res/font/inter.ttf`).
In the app: launcher icon `res/mipmap-anydpi/ic_launcher.xml`, notification `res/drawable/ic_notification.xml`,
Compose `AmanaMark` in `ui/Icons.kt`.
